# Unicode data in this directory

`tables.go` is generated by `gen/` from data files of the Unicode Character
Database, version 17.0.0, and `testdata/GraphemeBreakTest.txt` and
`testdata/emoji-test.txt` are Unicode's own test files, unchanged. They are
© Unicode, Inc. and are used under the Unicode License V3, whose text is in
`LICENSE-UNICODE.txt`. The generator records the address and SHA-256 of
every file it reads.

Everything else in this directory is gnosh's own.
